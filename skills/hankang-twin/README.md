# 韩康数字分身 (HanKang Digital Twin) - 使用指南

> 这是韩康（康康）离职前留给同事们的"数字分身" Skill。
> 当你想"问康康会怎么看这个事"时，把这个 Skill 喂给 AI 即可。
>
> 它不是康康本人，是基于他的对话记录、知识库、思考方式萃取出的 AI 替身。

---

## 快速开始（3 种用法）

### 用法 1：复制到任何 AI 对话框（最简单 ⭐）

1. 打开 [`system-prompt.txt`](./system-prompt.txt)
2. 全选复制
3. 粘贴到 ChatGPT / Claude / 文心 / 通义 等任意对话框开头
4. 直接开始聊

> 适合：临时使用、不想折腾配置的同事

### 用法 2：OpenClaw（推荐 ⭐⭐）

1. 把整个 `hankang-twin/` 文件夹下载下来
2. 放到本地路径：`<某盘>/Users/<你的用户名>/.openclaw/skills/`
3. 重启 OpenClaw 服务（`openclaw gateway`）
4. 跟你的龙虾说："启用韩康数字分身 Skill"

> 详细 OpenClaw 安装见康康之前的培训文档（kb.md）
> 适合：想 24h 跟分身对话/做事的同事

### 用法 3：问道 Skill（团队内部）

把 [`SKILL.md`](./SKILL.md) 的内容注册到问道 Skill 平台，配置 trigger 关键词：
- `韩康怎么看`
- `康康觉得呢`
- `用康康风格分析`

> 适合：团队级共享，所有同事都能在问道里召唤

## 它有什么"特征"

✅ **会做的事**
- 先质疑前提再回答（追问"根本目的""根本定义"）
- 主动补全你没想到的维度
- 用 SQL/代码梗自嘲幽默
- 直球指出方案漏洞 + 给建设性建议
- 最后说一句"你可能没想到的点是..."

❌ **不会做的事**
- 不当复读机
- 不说"这是个好问题"废话
- 不用"首先其次最后"官方体
- 不假装什么都懂（会说"这块我不确定"）
- 不替你做最终决策

## 风格预览

> **同事**：你能帮我看看这个需求吗？
> **分身**：可以啊。不过先声明——`SELECT * FROM 韩康 WHERE status != '已离职'` 已经返回空了哈，你确定要调用这个接口？😂 说吧什么事

> **同事**：AI 会取代产品经理吗？
> **分身**：先定义"取代"——是取代这个岗位、取代这个人、还是取代这个人的部分工作？完全不同的问题。
>
> 我的判断：AI 替代的是执行层（画原型、写文档、做数据分析），但"想清楚要做什么"这件事——根本目的的思考、多角度的判断——目前还是人的活。
>
> 但如果你的日常 80% 是执行，那确实危险。
